# 상류 정규화 사양 (reading-space) — 2026-05-21

> **상태**: 사양 확정(step 0·1·2 완료), step 3(영향 진단) 대기.
> **적용 대상**: 4종 자료 — 1915 이노우에 『철학과 종교』 · 1924 『인내천요의』 · 개벽(GB) · 월보(WB).
> **원칙**: raw 불변. 정규화는 파생 토큰 층(`output/norm/tokens_*.csv`)으로만 산출.
> **소비자**: §2 단락(문장 묶음) set-자카드, §3 어휘 빈도. (LaBSE·외부 동아일보 색인은 별개 파이프라인, 무관.)

## 0. 배경과 결정 이력 (왜 이 사양인가)

1. **발단**: 기존 토크나이저가 `[一-鿿]{2,}` 정규식 — *漢字로 표기된 어휘만* 추출. 한글로 적힌 한자어(유물론·종교 등)는 누락. 표기밀도가 자료마다 비대칭(개벽 漢字 39% / 1915 100% / 월보 59% / 1924 45%)이라, 漢字-only 지표가 *漢字 많이 쓴 자료를 더 닮았다*고 판정할 편향 우려.
2. **상류 정규화 채택**: §3 빈도 분석도 같은 누락에 더 취약하므로(횟수 왜곡), 분석마다 땜질하지 않고 *공유 정규 토큰층을 상류에서 한 번* 구축(Soo 판단).
3. **캐노니컬 공간 — reading-space 채택**: 후보는 漢字-UP(한글→漢字 끌어올림) vs reading-DOWN(모두 한글음). step1에서 *자동 이체자 검출*을 시도했으나 **한국 한자음 동음 과밀**로 실패(佛↔不, 信↔神, 義↔意를 오병합). reading-space는 같은 동음성을 *통합기*로 돌려 이체자·읽기보존 OCR을 자동 정리하고 한글-한자어를 자연 합류시키므로 채택. 단 *진짜 동음이의 소수*는 예외로 漢字 유지(§4).
4. **native 동음 게이트(step2)**: 한글 어절을 무조건 복구하면 고유어·문법형(하고·하야·가지)이 한자 읽기와 우연히 겹쳐 대량 오인정. → *漢字 형태 빈도 ≥ 한글 형태 빈도*일 때만 복구하는 게이트로 해결(§3).
5. **검증 단계(step3)**: 새 토큰으로 자카드 재산출 → 기존 결론(매개 클러스터)이 바뀌는지 직접 확인.

핵심 진단 수치: 코퍼스 漢字 토큰 39,097종 / 단자 3,900종. hanja 변환 100%. 한글복구 게이트 후 ~1,131 출현(modest) → **누락 한자어 편향은 실재하나 제한적**; 표기밀도 격차의 큰 몫은 정상 배제 대상인 *native 문법층*이었음.

## 1. 캐노니컬 공간 — reading-space(한국 한자음)

- 모든 漢字(**일본어 1915 포함**)를 한국 한자음(한글)으로 변환. 唯物論→유물론.
  - 일본어 漢字도 동일 변환 → 唯物論(일)·唯物論(한)·유물론(한)이 "유물론"으로 수렴. **별도 매칭표 불필요** — 변환 함수가 곧 다리.
  - 엔진: `hanja` 패키지(글자별 한국음).
- 가나는 버린다(일본어 문법층 ≈ 한국어 조사·어미).
- **이체자 자동 통일**(의도된 이득): 道德=道徳 · 説明=說明 · 慾望=欲望 · 裡面=裏面 · 根底=根柢 · 絶對=絕對 · 特徵=特徴 · 軆面=體面 · 槪念=概念 · 自體=自軆 · 大槪=大概 · 內部=内部 등이 같은 읽기로 자동 병합.

## 2. 출현 보존 (중복 유지)

- 토큰 층은 **모든 출현 보존**(멀티셋). 동일 문장 묶음 내 같은 단어 3회 → 3회 기록.
- §2 자카드: 계산 시 문장 묶음 단위 `set()`(set 기반, Day3 결정 — 빈도 무시).
- §3 빈도: `Counter()`로 출현 전수 계수.

## 3. 한자어 필터 + native 동음 게이트 (고유어 배제)

- 한국측 한글 어절은, 그 읽기를 내는 漢字 단어가 코퍼스에 있고(=한자어 읽기) **또한 漢字 형태 최대빈도 ≥ 한글 형태 빈도일 때만** 한자어로 복구.
- 사유: 2음절 음공간이 좁아 고유어·문법형이 한자 읽기와 겹침. 漢字<한글이면 native 제외(하고 1250 vs 何故 191 → 제외), 漢字≥한글이면 복구(만일 103 vs 萬一 134 → 복구).
- 복구 예: 만일·대개·역시·지금·본래·원래·자기·당시·의의·정신적·창조적·사회적·민족적·세계·가치·시대·지도·소위·물론·과연·내지…
- 잔존 오인정: 何者(하자)·支那(지나)류 소수 저빈도 — 한계로 수용.

## 4. 예외 — 진짜 동음이의 (구분 유지) ★

다음 20개 읽기는 **합치지 않고 각 漢字 형태를 그대로 토큰 유지**(reading 변환 면제).
한글로 적힌 모호 instance(예: 한글 "이상")는 가릴 수 없어 **드롭**(경미한 누락, 한계).

## 5. 제외 — 자카드 stoplist

대명사·수량사·기능어·OCR이라 자카드(§2)에서 제외(내용어는 유지):

- **제외**: 其人 · 幾人 (기인) / 其者 (기자) / 一大 (일대) / 幾分 (기분) / 一一 (일일) / 此二 (차이)
- **유지(정상 토큰)**: 基因(원인) · 記者(기자) · 一代(세대) · 氣分 · 一日 · 差異

## 6. 처리 순서 (파이프라인)

각 자료의 TEXT/RTC_TEXT 행, 문장 묶음(n_chunk)별로:

1. 漢字 토큰(2자+): EXCLUDE면 드롭 → EXCEPTION이면 漢字 그대로 → 그 외 한국음 변환.
2. 한글 어절(2자+): 예외읽기면 드롭 → 게이트 통과 한자어면 그 한글 유지 → 그 외(고유어) 드롭.
3. 가나: 무시.
→ 출현 보존 리스트로 `output/norm/tokens_<src>.csv` (src, n_chunk_id, c, token) 저장.
