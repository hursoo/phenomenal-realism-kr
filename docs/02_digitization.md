# 02. 원본에서 텍스트로 — 디지털화 절차

두 단행본이 종이에서 분석 가능한 텍스트가 되기까지의 전 과정이다. 각 단계의 산출물은
`data/`에 판(revision)별로 보존되어 있으므로, 이 문서는 **무엇을 왜 했는가**를 적고 **무엇이
바뀌었는가**는 파일의 차이가 말하게 한다.

---

## 0. 한눈에

```
① 저본 확보      NDL PID 952938 (1915) / 영인본 소장본 촬영 (1924)
② 페이지 분할     펼침면 → 낱쪽 → 여백 제거        → 832장 / 290장
③ 판독           Google Gemini 3.0                → 위계·문단·페이지 태그 포함 텍스트
④ 교정           1915 여덟 판 · 1924 다섯 판
⑤ 문장 경계 태깅  1924만 — 여섯 판
⑥ 문장 분리·ID   → DB v1.0 / v1.1
⑦ 정리           v1.2 장번호 재배열 → v1.3 빈 행 삭제
⑧ 묶음 단위 부여  v1.4 — n_chunk_id, local_id 5단 통일
```

⑨ 정규화와 ⑩ 유사도는 [`04_normalization.md`](04_normalization.md)와
[`05_similarity.md`](05_similarity.md)에서 다룬다.

## ① 저본

| | 『哲學と宗敎』(1915) | 『人乃天-要義-』(1924) |
|---|---|---|
| 저본 | 일본 국립국회도서관 디지털컬렉션 [PID 952938](https://dl.ndl.go.jp/pid/952938) | 편자 소장 영인본 |
| 형태 | PDF 231MB | PDF 15.6MB |

1924년 저본은 영인본(단행본 형식)이며, 같은 내용이 韓國學文獻硏究所 편, 『東學思想資料集』

원본 PDF와 페이지 이미지의 소재는 [`../IMAGES.md`](../IMAGES.md) 참조.

## ② 페이지 분할

스캔본은 **펼침면(見開き)** 상태다. 두 쪽이 한 장에 들어 있고 주변에 배경 여백이 있다. 이를
낱쪽으로 갈라야 페이지 번호와 텍스트가 맞물린다.

세 스크립트가 차례로 처리한다.

| 스크립트 | 하는 일 |
|---|---|
| `01_make_one_sheet.py` | PDF에서 낱장 이미지 추출 |
| `02_split_two_side.py` | 그레이스케일 → 가우시안 블러 → **Otsu 이진화 → 윤곽선 검출**로 책 영역을 찾고 좌·우로 분할 |
| `03_cut_extra_space.py` | 남은 배경 여백 제거 |

결과는 1915년 **832장**, 1924년 **290장**이다.

> 이 단계는 결정론적이므로 같은 원본에서 같은 결과가 나온다. 그래서 이미지 자체를 다시
> 만들 수 있고, 저장소가 이미지를 싣지 않아도 재현이 끊기지 않는다.

## ③ 판독 (OCR)

**도구는 Google Gemini 3.0이다.** 통상적인 문자 인식 엔진이 아니라 멀티모달 언어모델을 쓴
까닭은 두 가지다.

1. **국한문 혼용체와 일본어 고어의 인식 성능.** 1924년 책은 한자와 한글이 섞이고 옛 표기가
   많으며, 1915년 책은 구자체 일본어다. 일반 OCR 엔진의 인식률이 낮았다.
2. **위계 인식.** 목차와 지면의 조판을 함께 보고 장·절·항의 위계와 문단 구분을 판정하게 했다.
   이것이 뒤의 ID 체계로 곧장 이어진다.

이 선택의 대가는 [`06_ai_disclosure.md`](06_ai_disclosure.md)에 적었다. **요점은 언어모델의
오독이 깨진 글자가 아니라 문맥에 맞는 다른 글자로 나타난다는 것이다.**

### 산출물의 형식

두 책의 형식이 다르다. 이 차이가 뒤의 단위 비교에 영향을 준다.

| | 1915 `final_result_v7.2` | 1924 `인내천요의tag_v3.1_plus` |
|---|---|---|
| 행수·크기 | 747행 · 1,139KB | 521행 · 322KB |
| 위계 | `#` 장 / `##` 절 | `#` 장 / `##` 절 / `### [항]` |
| 문단 | 한 줄 = 한 문단 | 한 줄 = 한 문단 |
| **문장 구분** | `。` 뒤 공백 (암묵) | **`\|` 파이프로 명시** |
| 페이지 | `<a0>`·`<b1>`·`<10>` 인라인 태그 804개 | `<0>`·`<6>`·`<15>` 인라인 태그 |

1915년 텍스트의 앞머리는 이렇다.

```
哲學と宗敎
文學博士 井上哲次郎 著
東京 弘道館發行<a0>
# 哲學と宗敎 序
近來我邦に於て哲學を云爲する者、…<a1>…思想を蠱惑すること甚し。…<a4>
```

1924년 텍스트는 이렇다.

```
# 第一章 緖言
## 第一節 新社會에 要하는 宗敎的 精神
### [無宗敎와 有宗敎]
現代 사람들의 宗敎에 對한 見解는 두 가지 다른 觀察을 가지고 잇나니|하나은 科學的 信奉의…
```

**⚠️ 문장 분리의 근거가 두 책에서 다르다.** 1915년 책은 일본어 구두점(`。`)이 있어 기계적으로
가를 수 있으나, 1924년 책은 국한문 혼용에 마침표가 드물어 기계가 문장 끝을 잡을 수 없다.
그래서 **판독 단계에서 문장 경계를 파이프로 명시**했다. 파일 이름의 「tag」가 그것이다.

이 비대칭은 문장 수를 단위로 삼는 비교에 영향을 준다. 코퍼스를 쓰는 사람은 알고 써야 한다.

**1924년 항 제목의 대괄호.** `### [無宗敎와 有宗敎]`처럼 항 제목이 대괄호로 묶여 있다.
**원문 대조로 확인한 결과, 항 제목은 원본에 있는 것이다.** 대괄호는 판독 단계에서 붙인
구조 표시다. 원본이 항 제목 바로 뒤에 줄을 바꾸지 않고 본문 첫머리를 잇기 때문에, 제목과 본문의
경계를 표시할 장치가 필요했다. **목차에서 끌어와 심은 것이 아니다.**

**페이지 태그.** 문단 **안**에 박혀 있다(1915 기준 804개). 원본 지면의 경계를 가리키며, 이
대응은 원문 대조로 확인했다. `page_info` 열이 여기서 나온다.

**문단 안에 박힌 것은 오류가 아니라 설계다.** 판독 결과는 원래 `[[Page 1 Start]]` …
`[[Page 1 End]]` 형식이었고, 후처리에서 `<1>` 하나로 줄였다. 이때 규칙이 이러했다 —
**페이지 표시 앞에 종결 부호나 줄바꿈이 있으면 그대로 두고, 없으면 뒤의 줄바꿈을 지워 다음 쪽의
첫 낱말과 잇는다.**

```
考へられます。          考へられます。<1>
<1>            →        第一は
第一は

驚きを以て之
<3>            →        驚きを以て之<3>に對すると云ふ
に對すると云ふ
```

곧 **쪽이 바뀌며 잘린 문장을 이어 붙이되 경계 표시는 남긴 것**이다. 태그를 지우면 원래의 이어진
문장이 나온다. 이 후처리 명세는 `data/3_corpus/revisions/1915/n8n_code_node.txt`에 있다.

> ⚠️ 위 둘은 **확인했다는 것이지 오류가 없다는 뜻이 아니다.** 804개의 태그와 수백 개의 항
> 제목을 하나하나 전수 대조한 것은 아니므로, 개별 자리에서 어긋남이 남아 있을 수 있다.
> 중요한 인용의 쪽수를 다룰 때는 원본 이미지를 함께 보기를 권한다.

## ④ 교정

판독 결과를 여러 판에 걸쳐 고쳤다. **모든 판이 `data/1_ocr_text/revisions/`에 있다.**

**1915년 — 여덟 판**

```
final_result_v4.0(3.0교정반영)   ← 앞 판의 교정을 반영한 판
final_result_v5.1_complete
final_result_v5.2_fixeding
final_result_v5.3(new2old)      ← 자체(字體) 변환으로 보임
final_result_v5.3(new2old)_plus
final_result_v6.0(20250104)
final_result_v7.0(20250108)
final_result_v7.1(20250109)
final_result_v7.2(20250111)     ← 최종
```

**1924년 — 다섯 판**

```
인내천요의ocr_v1.0 → v2.0 → v3.0 → v4.0 → v4.0_plus
                                    └ v4.0_plus_omitted.txt   ← 누락분 별도 추적
```

`_omitted`가 따로 있는 것은 **판독이 빠뜨린 부분을 버리지 않고 추적했다**는 뜻이다.

### 후처리가 어떻게 돌았는가

같은 폴더에 후처리의 실물 기록이 셋 남아 있다.

| 파일 | 내용 |
|---|---|
| `n8n_code_node.txt` | 판독 결과를 정리하는 절차 명세 — 빈 줄 제거, 구분선 제거, 페이지 표시 변환, 쪽 경계 잇기 |
| `일본어_문장부호정리.txt` | 남길 문장부호와 반복 기호(々〃ゝゞ)의 정규식 |
| `추가작업분_파일명.txt` | 재작업이 필요했던 페이지 목록 (C001.jpg · C052.jpg 등) |

**자동화 도구(n8n)의 코드 노드로 돌렸고, 명세의 마지막 항이 「여기까지 하고 사용자의 검수를
기다립니다」다.** 곧 자동 처리와 사람 검수가 교대로 들어갔다.

> **다만 판 사이의 실제 차이는 대조하지 않았다.** 파일명이 가리키는 바(예: `v5.3(new2old)`가
> 자체 변환)는 추정이며, 확정하려면 판을 견주어야 한다. 판을 모두 실은 것은 그 대조를 누구나 할
> 수 있게 하기 위해서다.

교정된 텍스트에 위계와 문장 경계를 넣었다.

```

```

1915년 책은 구두점으로 문장을 가를 수 있어 이 단계가 없다.

## ⑦ 정리

**v1.2 — 장 번호 재배열.** 1915년 책의 장 번호를 하나씩 당겼다(C01→C00, C02→C01 …). 序를
C00으로 두어 본론 26장이 C01~C26, 附錄 둘이 C27·C28이 되게 한 것이다. 행수는 그대로 11,167.
1924년 책에서는 「人乃天의 要義」 행 하나를 지워 2,255 → 2,254가 됐다(그 행은 `STRUCT`였다).

**v1.3 — 빈 행 삭제.** 1915년 책에서 `kr_text`가 빈 79행을 지워 11,088행이 됐다.

> 🔴 **이때 문단이 633에서 626으로 줄었다.** 판독이 문단 구획으로 잡았으나 텍스트가 없던 문단
> 일곱이 함께 사라진 것이다. 이 저장소에서 문단 수가 633과 626 두 값으로 나오는 까닭이며,
> **어느 버전으로 산출한 수치인지 반드시 밝혀야 한다.**

⚠️ **v1.2 파일은 유실됐다.** v1.1과 v1.3을 대조하면 재현된다.

## ⑧ 묶음 단위 부여 (v1.4)

여러 자료를 함께 다루기 위해 두 가지를 더했다.

1. **`local_id` 5단 통일** — 1915년 책에는 항(項) 층이 원래 없다. 통합을 위해 `I00`을 강제로
   넣어 `C##-S##-I##-P##-S##`로 맞췄다.
2. **`n_chunk_id`** — 연속 다섯 문장을 한 묶음으로 자른 비교 단위. 형식은
   `C##-S##-I##-N##`이며, 묶음 번호는 **항(I) 단위로 초기화**한다. 마지막 자투리는 문장 수가
   3 이상이면 독립 묶음, 2 이하면 앞 묶음에 합친다.

결과는 1915년 **2,195묶음**, 1924년 **424묶음**이다.
