# 01. 원사료

이 코퍼스가 딛는 두 책의 서지다. **판권지를 직접 판독해 확정했으며**, 선행연구의 표기와
갈리는 자리는 그 사실을 함께 적는다.

---

## 1. 『哲學と宗敎』 (1915)

### 서지

```
井上哲次郞, 『哲學と宗敎』, 東京: 弘道館, 1915.
```

**판권지 실측**

| 항목 | 내용 |
|---|---|
| 인쇄 | 大正四年二月九日 |
| 발행 | **大正四年二月十二日** |
| 著作者 | 井上哲次郞 (東京市 神田區 北神保町 十一番地) |
| 發行者 | 辻本卯藏 (東京市 牛込區 榎町 七番地) |
| 印刷者 | 渡邊八太郎 |
| 印刷所 | 日淸印刷株式會社 (東京市 牛込區 榎町 七番地) |
| 發行所 | 弘道館 (東京市 神田區 北神保町 十一番地) |
| 연락 | 電話 本局 三四三二番 · 振替口座 東京 八一五番 |
| 정가 | 正價 金貳圓 |
| 권리 표시 | 複製不許 |

著作者와 發行所의 주소가 神田區 北神保町 十一番地로 같다.

### 구성

序 1편 + 본론 26편 + 附錄 2편 = **29장**. 저자 서문이 밝히듯 「哲學に關する者、十一篇、宗敎に
關する者、十五篇、總て二十六篇」을 모아 한 책으로 엮고, 「日本民族の起源に關する考證」과
「近時の日本人種論」을 附錄으로 더한 것이다. 附錄 둘은 제26장 「日本神話の新解釋」과 관련이
있어 함께 실었다고 밝힌다.

서문의 말미는 「大正四年一月三十日 文學博士 井上哲次郎 識す」다.

## 2. 『人乃天-要義-』 (1924)

### 서지

```
李敦化, 『人乃天-要義-』, 京城: 天道敎中央宗理院布德課, 1924.
인용은 韓國學文獻硏究所 편, 『東學思想資料集』 3, 아세아문화사, 1979 수록본에 따른다.
```

**판권지 실측**

| 항목 | 내용 |
|---|---|
| 初版 | 大正十三年三月三十日 (1924. 3. 30.) |
| 再版 | 大正十四年二月二十日 (1925. 2. 20.) |
| 三版 | 昭和三年一月廿三日 (1928. 1. 23.) |
| 著作兼發行人 | 李敦化 (京城府 慶雲洞 八八番地) |
| 印刷人 | 李斗星 (京城府 慶雲洞 八八番地) |
| 印刷所 | 大東印刷株式會社 (京城府 公平洞 五五番地) |
| 發行所 | **天道敎中央宗理院布德課** (京城府 慶雲洞 八八) |
| 연락 | 電話 光化門 五一八 · 振替 京城 一三六三 |
| 정가 | 改正定價 五十錢 · 書留送料 十六錢 |
| 권리 표시 | 版權所有 |

**著作兼發行人 李敦化의 주소와 發行所의 주소가 慶雲洞 八八로 같다.** 저자와 발행 주체가 한자리에
있다.

⚠️ 發行所 항목 왼쪽에 작은 글자로 「崔碩連」이 있다. 布德課 쪽 담당자인지 후대의 기입인지
판정하지 않았다.

### 🔴 발행처 표기의 정정

선행연구에서 이 책의 발행처가 갈린다.

| | 표기 |
|---|---|
| 허수(2011) 〈그림 1〉 출전 | 開闢社 |
| 허수(2011) 참고문헌 | 天道敎中央宗理院布德課 |
| **판권지 실물** | **天道敎中央宗理院布德課** |

**판권지가 뒤의 것을 지지한다.** 같은 연구 안에서 갈린 것이므로 어느 한쪽이 오기다.

### 구성

6장. 문단 365(본문 기준) · 문장 2,108 · 글자(공백 제외) 94,671.

| 장 | 제목 |
|---|---|
| C01 | 第一章 緖言 |
| C02 | 第二章 人乃天과 天道 |
| C03 | 第三章 人乃天과 眞理 |
| C04 | 第四章 人乃天의 目的 |
| C05 | 第五章 人乃天의 修煉 |
| C06 | 第六章 人乃天에 對한 雜感 |

제3장 제4절 「人乃天의 哲理」가 일곱 항으로 되어 있다 — 「實現思想과 人乃天」·「實在와
人乃天」·「汎神觀과 人乃天」·「生命과 人乃天」·「意識과 人乃天」·「靈魂과 人乃天」·「進化와
人乃天」. 두 책을 맞대는 분석이 집중되는 자리다.

### 저본

**편자 소장 영인본(단행본 형식)을 직접 촬영했다.** 같은 내용이 『東學思想資料集』 3에 수록되어
있으며, **학술 인용은 자료집을 기준으로 삼는 것이 정확하다.**

판권지가 初版·再版·三版을 누적 기재하므로 **저본은 三版(昭和3년, 1928)으로 본다**(아래 §5-3).

영인본의 본문 지면은 원저작물의 단순 복제이므로 새 권리가 생기지 않는다. 다만 자료집의
해제·편집 부분은 별개이며 이 저장소에서 쓰지 않는다.

## 3. 판권지가 확인해 주는 것

두 책의 판권지는 서지를 확정할 뿐 아니라 **다른 자료와 교차 검증되는 자리**이기도 하다.

- 『인내천요의』는 초판 발행 여드레 뒤(1924. 4. 7.)와 재판 발행 엿새 뒤(1925. 2. 26.)에
  『동아일보』에 광고가 실린다. **두 게재일이 판권지의 발행일을 독립적으로 확증한다.**
- 1915년 책 서문의 「大正四年一月三十日」과 판권지의 「大正四年二月十二日 發行」이 서로 어긋나지
  않는다.

자체에는 어떤 제약도 더하지 않는다.

## 5. 알아 둘 것

1. **1915년 책은 강연 모음이다.** 스물아홉 장이 각각 독립된 강연이므로, 인용 위치를 장 제목으로
   지시하면 충분하다.
2. **1924년 책의 인용은 절·항 이름으로 지시하는 편이 낫다.** 인용이 대부분 제3장 「人乃天과
   眞理」의 哲理 절에 몰리기 때문이다.
3. **저본은 三版(1928)으로 본다.** 판권지가 初版·再版·三版을 모두 적고 있는데, 판권지는 그
   책 자신의 것이므로 **세 판을 누적 기재했다는 것은 그 책이 三版이라는 뜻**이다. 이런 경우
   가장 나중 판을 스캔한 것으로 간주하는 것이 통례다.

   ⚠️ 따라서 **인용은 1924년 초판으로 표기하되 이 코퍼스가 딛는 실물은 1928년 삼판이다.**
   판 사이에 본문의 이동(異同)이 있다면 그 차이는 이 코퍼스에 반영되지 않는다. **판 사이의
   대조는 하지 않았다.**
