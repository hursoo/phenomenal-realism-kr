# 03. DB 구조

판독 텍스트를 문장 단위 행으로 펼치고 계층 ID를 매긴 결과가 이 DB다. 두 책은 같은 스키마를
쓰되 **원래의 층 구조가 달라** ID 체계가 갈린다.

---

## 1. 파일

| 버전 | 1915 | 1924 | 성격 |
|---|---|---|---|
| v1.0 | `BK_IT_1915_PR_v1.0.xlsx` | `BK_YD_1924_IY_v1.0.xlsx` | 초기 |
| v1.1 | `_v1.1.xlsx` · `_v1.1.csv` | `_v1.1.xlsx` · `_v1.1.csv` | 원본 |
| v1.2 | **유실** | `_v1.2.xlsx` | 정리 |
| v1.3 | `_v1.3.xlsx` | — | 정리 |
| v1.4 | `_v1.4.xlsx` | `_v1.3.xlsx` | 통합 (묶음 ID 추가) |

⚠️ **버전 번호가 두 책에서 어긋난다.** 1924년 책은 v1.2에서 정리가 끝나 v1.3이 곧 통합본이고,
1915년 책은 정리가 v1.2·v1.3 두 단계라 v1.4가 통합본이다. **파일명의 숫자가 아니라 아래 이력을
보고 판단해야 한다.**

## 2. 버전 이력

### 1915

| 버전 | 변경 | 행수 | 문단 |
|---|---|---|---|
| v1.0 · v1.1 | 초기·원본 | 11,167 | **633** |
| v1.2 | 장 번호 재배열 (C01→C00, C02→C01 …) | 11,167 | 633 |
| v1.3 | **빈 `kr_text` 79행 삭제** | 11,088 | **626** |
| v1.4 | `n_chunk_id` 추가, `local_id` 5단 통일 | 11,088 | 626 |

**v1.2의 장 번호 재배열**은 序를 C00으로 내려 본론 26장이 C01~C26, 附錄 둘이 C27·C28이 되게 한
것이다.

🔴 **v1.3에서 문단이 633 → 626으로 줄었다.** 빈 행 79개를 지울 때 **텍스트가 없던 문단 일곱이
통째로 사라졌다.** 판독이 문단 구획으로는 잡았으나 내용이 비어 있던 자리다.

## 3. 열 구조

```
uid · book_id · local_id · page_info · line_class · kr_text ·
structure_id · parent_id · depth_level · sort_order
```

| 열 | 설명 | 예 |
|---|---|---|
| `uid` | 전역 고유 식별자 | `BK_IT_1915_PR_00001` |
| `book_id` | 자료 코드 | `BK_IT_1915_PR` |
| `local_id` | 계층 위치 | `C02-P19-S04` |
| `page_info` | 원본 쪽 | `54` |
| `line_class` | 행 유형 | `TEXT` · `STRUCT` · `ANNOTATION` · `RTC_TEXT` |
| `kr_text` | 본문 (전처리 **전** 원문) | |
| `structure_id` | 소속 구조 | `C02` |
| `parent_id` | 상위 구조 | `C02` |
| `depth_level` | 계층 깊이 | 0 · 1 · 2 · 3 · 10 · 99 |
| `sort_order` | 정렬 순서 | 1, 2, 3 … |

통합본(v1.4 / v1.3)에는 다음이 더해진다.

| 열 | 설명 |
|---|---|
| `n_chunk_id` | 비교 단위 — 연속 다섯 문장 묶음. `C##-S##-I##-N##` |
| `local_id_unified` | 5단으로 맞춘 `local_id` |

`kr_text`는 **정규화 전 원문**이다. 정규화 결과는 별도 토큰 층으로 나가며 DB를 덮지 않는다
([`04_normalization.md`](04_normalization.md)).

## 4. 행 유형

| | TEXT | STRUCT | ANNOTATION | RTC_TEXT | 계 |
|---|---|---|---|---|---|
| 1915 v1.1 | 11,055 | 48 | 30 | 34 | 11,167 |
| 1915 v1.3 | 10,976 | 48 | 30 | 34 | 11,088 |
| 1924 v1.1 | 2,108 | **109** | 28 | 10 | 2,255 |
| 1924 v1.2 | 2,108 | **108** | 28 | 10 | 2,254 |

1924년 책의 `STRUCT`가 109 → 108로 하나 준다. **v1.2에서 지운 「人乃天의 要義」 행이
`STRUCT`였음이 이로써 확인된다.**

`RTC_TEXT`는 루비(ruby) 텍스트다 — 본문 옆에 달린 독음.

### 빈도 카운트 기준

- **포함** — `line_class`가 `TEXT` 또는 `STRUCT`
- **제외** — `RTC_TEXT` · `ANNOTATION`, 그리고 `structure_id`가 `TOC` 또는 `ROOT`

## 5. 계층

| `depth_level` | 1915 | 1924 | 뜻 |
|---|---|---|---|
| 0 | 1 | 1 | ROOT (책 전체) |
| 1 | 29 | 6 | 장 |
| 2 | 18 | 25 | 절 |
| 3 | **—** | 75 | 항 |
| 10 | 11,010 | 2,117 | 본문 |
| 99 | 30 | 28 | 주석 |

🔴 **1915년 책에는 항(項) 층이 없다.** 이것이 두 책의 ID 체계가 갈리는 까닭이다.

## 6. ID 체계

### 1915

```
C##-P##-S##          기본 — 절이 없는 장
C##-S##-P##-S##      절이 있는 장
```

**절이 있는 장은 넷뿐이다** — C01(序論·第一·第二) · C13(一~六) · C14(一~五) · C20(一~四).

### 1924

```
C##-S##-I##-P##-S##      장-절-항-문단-문장
```

### 통합본에서의 처리

여러 자료를 함께 다루기 위해 1915년 책에 **`I00`을 강제로 넣어** 다섯 단으로 맞췄다.
`C02-P19-S04` → `C02-S00-I00-P19-S04`.

**이 `I00`은 실재하는 층이 아니라 자리맞춤이다.** 1915년 책에서 항 단위 분석을 시도해서는 안
된다.

### 묶음 ID

```
n_chunk_id = C##-S##-I##-N##
```

- 연속 **다섯 문장**을 한 묶음으로 자른다(비중첩).
- 묶음 번호는 **항(I) 단위로 초기화**한다.
- 마지막 자투리는 문장 수가 3 이상이면 독립 묶음, 2 이하면 앞 묶음에 합친다.

결과는 1915년 **2,195묶음**, 1924년 **424묶음**이다.

## 8. 텍스트 통계

| | 1915 | 1924 |
|---|---|---|
| TEXT 행수 | 10,976 | 2,108 |
| 총 글자수(공백 포함) | 381,392 | 122,655 |
| 총 글자수(공백 제외) | 381,049 | 94,671 |
| 평균 문장 길이 | 34.7자 | 58.2자 |
| 최소 / 최대 | 2 / 218 | 1 / 233 |

⚠️ **공백 포함과 제외를 섞으면 안 된다.** 1924년 책은 두 값이 122,655와 94,671로 크게 다르다.
분량 비를 「약 4배」로 적은 문서는 **공백 제외** 기준이고, 「약 3.1배」는 공백 포함 기준이다.
같은 자료를 두고 다른 값이 나오는 것은 이 때문이다.

## 9. 파일 명명 규칙

```
BK_[저자코드]_[연도]_[텍스트코드]_v[버전].xlsx

BK  Book
IT  Inoue Tetsujiro   PR  Philosophy and Religion
YD  Yi Don-hwa        IY  Innaecheon Yoeui
```

잡지 코퍼스가 더해지면 `MA_[저자코드]_[시기]_[매체코드]` 형식을 쓴다
(`MA_YD_10-20_GB` = 개벽, `MA_YD_10-20_WB` = 천도교회월보).
