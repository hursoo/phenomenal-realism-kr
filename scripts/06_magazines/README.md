# 잡지 도구 — 지면에서 정본까지

『천도교회월보』의 지면을 텍스트로 만들고, 그 텍스트가 얼마나 믿을 만한지 재고, 미더운
쪽으로 밀어 올리는 도구들이다. **순서가 있다.** 아래는 그 순서다.

각 도구의 자세한 설명은 파일 첫머리 docstring에 있다 — 왜 만들었고, 무엇이 되고 무엇이
안 되는지가 거기 적혀 있다.

---

## 1. 지면을 단(段)으로 가른다

세로쓰기 지면은 위·아래 두 단으로 나뉘고 가는 물결선이 그 경계다. 이 단계에서 어긋나면
**뒤의 모든 것이 조용히 틀린다** — 글자가 사라지는 것이 아니라 자리를 옮기고, 두 엔진이
같은 이미지를 받으므로 마커조차 서지 않는다.

| 도구 | 무엇 |
|---|---|
| `detect_divider.py` | 지면마다 **진짜 구분선**을 찾아, 분리에 쓴 값과 얼마나 어긋났는지 잰다 |
| `fill_units_detected_divider.py` | 검출값으로 단 좌표를 다시 채운다. **위아래를 겹쳐** 자른다 |
| `detect_cut_glyphs.py` | 단 가장자리에 걸려 잘린 글자를 전수로 찾는다 |
| `audit_column_split.py` | 컬럼 검출이 **글줄을 몇 개나 삼켰는지** 잰다 (API 안 씀) |

> 🔴 2026-08-12 실측 — 분리에 쓰던 `divider_y=1180`은 5표본에서 잰 값이었다. 375면을
> 재 보니 **92.8%가 15px 넘게, 78.4%가 한 글자 넘게** 어긋났다(중앙값 −69px).

## 2. 판독한다

| 도구 | 무엇 |
|---|---|
| (워크벤치) `run_gemini_ocr.py`·`run_claude_ocr.py` | 단 이미지를 두 엔진에 넣는다 |
| (워크벤치) `consensus.py` | 두 판독을 합쳐 초벌본을 만든다. 갈린 자리는 `⚠️[C:…\|G:…]` 마커로 남는다 |
| `wolbo_markers.py` | 그 마커를 등급을 붙여 해소한다 — 규칙·대장·C·G·미해소·면주 |

## 3. 무른 데를 찾는다

| 도구 | 무엇 |
|---|---|
| `screen_wolbo_keywords.py` | 낱말을 세되 **마커를 두 판으로 펴서** 센다. 단순 검색은 과소 계수한다 |
| `engine_agreement_counts.py` | 「N회」 대신 **하한~상한**으로 적는다 |
| `build_keyword_index.py` | 엔진 원출력에서 출현 자리를 뽑아 색인을 만든다 |
| `build_corpus_status.py` | 편마다 얼마나 무른지 한 표로 |
| `audit_source_pages.py` | 지면 폴더가 각각 무엇인지 가른다 (편·중복·별판·편외) |

## 4. 밀어 올린다

지면을 다시 보는 일이다. **값이 드는 순서대로** 적는다.

| 도구 | 무엇 | 값 |
|---|---|---|
| `read_seam.py` | 단 경계의 **이음매 띠**만 다시 읽어 어긋난 자리를 메운다 | 지면당 1회 |
| `reread_columns.py` | **글줄 하나씩** 3~4배로 확대해 다시 읽힌다 | 글줄당 1회 |
| `rank_units_for_reread.py` | 어느 단부터 걸지 **깔끔함 점수**로 정한다 | 0 |
| `locate_marker.py`·`png_crop.py`·`detect_columns.py` | 마커 자리를 잘라 눈으로 보게 한다 | 0 |
| `resolve_markers_by_image.py` | ⚠️ 마커를 **글자 단위로 겨눠** 묻는다 — **실패한 길**. 기록으로 둔다 | |

> **글자를 겨누는 방식은 실패했고 글줄을 통째로 읽히는 방식은 됐다.** C30 정답지에서
> 앞의 것은 A/B 택일 1/9로 기준선 이하였고, 뒤의 것은 정본 대비 68.7% → **88.7%**였다.
> 까닭은 하나다 — 마커→지면 자리잡기가 아직 못 믿을 물건이고, 글줄은 겨눌 것이 없다.

## 5. 잰다

| 도구 | 무엇 |
|---|---|
| `score_readings.py` | 정본이 있는 편에서 **판독들을 정본과 견준다.** 어느 판독이 얼마나 가까운가 |
| `mine_marker_decisions.py` | 정본과 초벌을 정렬해 「사람은 이렇게 정했다」의 표를 뽑는다 |
| `build_reference.py` | 답이 붙은 지면 표본을 뽑아 판정 기준을 세운다 |

**정본 열 편이 이 저장소의 자(尺)다.** 새 방법을 들일 때마다 거기서 재고 나서 쓴다.
「더 잘 읽힌다」는 인상은 재기 전까지 인상일 뿐이다.

## 6. 내놓는다

| 도구 | 무엇 |
|---|---|
| `build_reading.py` | 마커를 해소한 **읽기용 본문**을 만든다. 해소 방식을 글자마다 표시한다 |
| `convert_wolbo_to_unified.py`·`convert_gaebyeok_to_unified.py` | 분석용 통일 DB로 옮긴다 |

## 지켜 온 것 셋

1. **못 찾는 것이 틀리게 찾는 것보다 낫다.** 구분선 검출 범위를 넓히면 사진 윤곽을
   구분선으로 잡는다(C30 1면 실측). 그래서 범위를 좁게 두고, 못 찾으면 고정값을 유지하며
   **그 사실을 적는다.**
2. **자동으로 해소한 것을 「확인」이라 부르지 않는다.** 규칙·대장·기계 판독·사람의 대조는
   등급이 다르고, 그 등급이 산출물에 그대로 남는다.
3. **재기 전에는 쓰지 않는다.** 정본 9편이 그 자리다.
