# 원문 대조를 마친 대목

『천도교회월보』 전사본은 대부분 3엔진 자동 합의의 **초벌**이다
([`../../../docs/02b_digitization_magazines.md`](../../../docs/02b_digitization_magazines.md) §2).
그래서 **연구 서술에서 직접 인용하는 대목은 편 단위 검수와 별도로 그 지면을 원본 스캔과
대조해 확정한다.** 이 파일은 그 대조의 기록이다.

이 파일에 없는 대목은 대조하지 않은 것이다. 전사본을 인용하려는 사람은 여기에 있는지 먼저
보고, 없으면 직접 `source_pages/`의 지면과 대조하기 바란다.

| 대조 | 편 | 지면 | 대상 |
|---|---|---|---|

## 1. C81 — 「大神師性靈出世說(其四)」

| | |
|---|---|
| 필자 | 李敦化 (지면 표기 확인) |
| 게재 | 『천도교회월보』 제98호, 1918년 10월 15일, **敎理部** |
| 시작 쪽 | 월보 14쪽 (스캔 213면, `source_pages/81_大神4_1918-10/page_001.jpg`) |
| **대조한 쪽** | **월보 15쪽** (스캔 214면, `page_002.jpg`) |
| 판별 | `articles/81_大神4_1918-10/` — **초벌**(`draft_v0` 계열). 이 대목만 대조 |

### 원문

> …羅馬의 文明이 一層 歐州現世의 文明으로 移轉ᄒᆞᆷ과 如ᄒᆞᆷ은 規則잇고 系統잇ᄂᆞᆫ 潮流임을
> 吾人은 社會的 精神內에셔 發見ᄒᆞᆯ 수 有ᄒᆞ며, 又 此를 特殊ᄒᆞᆫ 一方面으로 觀ᄒᆞᆯ지라도
> **唯心論이 唯物論으로 化ᄒᆞ며 唯物論이 更히 物心合一論으로 變**ᄒᆞ엿스며, 宗敎的 方面으로ᄂᆞᆫ
> 多神觀이 一神觀으로 變ᄒᆞ며 一神觀이 更一層 調和觀…

### 대조 결과

**자동 전사가 원문과 일치한다.** 굵게 표시한 대목에 판독 차이가 없다.

### 함께 확인한 것

- 이 글의 **제2절 제목이 「死生問題解決」**이다(page_001 하단). 「吾人은 前號에서 吾敎의
  死生問題는 輪回說도 아니오 天堂極樂說도 아니며 幽靈說도 아니며…」로 시작한다.
- 같은 쪽에 「**吾敎의 死生觀은 最發達ᄒᆞᆫ 眞理的 實際的 死生觀**」이 있다.
- 필자 표기 `李敦化`와 게재란 `敎理部`를 지면에서 확인했다.

### 판독의 값

唯心論·唯物論·物心合一論의 **삼항 구도**가 1918년에 이미 쓰였음을 보인다. 다만 그 문맥은
앗시리아→희랍→로마의 문명 이전, 석가→아난→달마의 법통과 나란히 놓인 **학설의 시간적
계승**이며, 동시대인을 세 갈래로 가르는 분류가 아니다.

## 2. C56 — 「天道敎六十一歲花甲庚申을 迎함」

| | |
|---|---|
| 필자 | 李敦化 (지면 표기 확인) |
| 게재 | 『천도교회월보』 제113호, 1920년 1월 15일, **敎門訂議** |
| 시작 쪽 | 월보 7쪽 (스캔 12면, `source_pages/CNTS-00048065337/page_001.jpg`) |
| **대조한 쪽** | **월보 8~9쪽** (스캔 13~14면, `page_002.jpg`·`page_003.jpg`) |
| 판별 | `articles/CNTS-00048065337/` — **초벌**. 이 대목만 대조 |
| ⚠️ | `meta.json`에 `partial: true` — 7쪽 이후가 빈 응답으로 와서 6장만 받았다 |

### 원문

제2절 「二、天道와 庚申年」 안이다. **쪽을 넘어 이어진다** — 앞은 8쪽 끝, 뒤는 9쪽 첫머리다.

> (8쪽) 孔子는 彼의 一部를 覺ᄒᆞ야 **仁**이라 ᄒᆞ고 釋迦는 彼의 一部를 覺ᄒᆞ야 **慈悲**라 ᄒᆞ고
> 耶蘇는 彼의 一部를 覺ᄒᆞ야 **愛**라 ᄒᆞ니, 其他 **科學者는 此를 勢力**이라 ᄒᆞ며 **哲學者는 此를
> 美善眞이라 實在**라 ᄒᆞ며 理性이라 ᄒᆞ도다. 然이나 其等 先哲은 아직 過去 幼稚ᄒᆞᆫ 時代
>
> (9쪽) 에 在ᄒᆞ야 僅히 其 一面의 圭角을 得ᄒᆞᆯ 뿐으로 **其의 全體原理를 把得지 못ᄒᆞᆫ 結果ㅣ
> 古今千載에 敵論이 紛紛**ᄒᆞ엿도다. 吾人은 此 全體原理를 直稱ᄒᆞ야 天道라 ᄒᆞ엿도다.

### 대조 결과

**자동 전사가 원문과 일치한다.** 굵게 표시한 대목에 판독 차이가 없다.

### 함께 확인한 것

- 필자 표기 `李敦化`와 게재란 `敎門訂議`를 지면에서 확인했다(page_001).
- 절 구성은 「一、大神師와 庚申年」 「二、天道와 庚申年」 「三、信徒와 庚申年」이다.
- 9쪽에 大神師 초상 도판이 실려 있다.

### 판독의 값

**科學者/哲學者라는 분류 어휘**와 **哲學者에 대한 實在의 귀속**이 1920년에 이미 쓰였고,
「敵論이 紛紛」에 **여럿이 갈려 다툰다는 문제의식**까지 있음을 보인다. 다만 이것은 하나를
여럿이 달리 부른다는 **열거**이며, 셋으로 가른 구도가 아니다.

## 대조 절차

1. 대상 편의 `source_pages/<편>/page_*.jpg`를 편 순서대로 연다.
2. 인용하려는 대목이 실린 쪽을 지면의 인쇄 쪽번호로 특정한다.
3. 글자 단위로 자동 전사와 맞춘다. 어긋나면 **지면을 정본으로 삼고** 전사를 고치는 것이
   아니라 인용문을 지면대로 적는다(전사본은 `articles/`의 산출물이며 이 파일이 그것을 덮어쓰지
   않는다).
4. 필자 표기·게재란·시작 쪽을 함께 확인해 서지를 확정한다.
5. 이 파일에 대조 날짜·지면·원문·결과를 적는다.
