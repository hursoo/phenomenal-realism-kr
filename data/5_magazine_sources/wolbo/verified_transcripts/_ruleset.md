# 천도교회월보 검수 규약 (wolbo54)

54편 OCR 초벌본(`*.high_fidelity.draft_v0.md`)을 이미지 대조로 정본화할 때의 확정 규약.
2026-07-01 Soo와의 협의로 정립. **자동화는 아래 확정 규칙에만 적용하고, 규칙 밖은 전부 사람 눈(이미지 대조)으로 넘긴다.** 규칙셋이 자랄수록 자동채움률이 오른다.

## 0. 검수 파이프라인 (4단)

0. **구조 선분리** — 면주·면번호·캡션·기사경계 침입을 마커 판단 *이전*에 걷어냄(§7). 매니페스트로 탐지·확인 후 분리.
1. **자동채움** — 초벌본의 `⚠️[C:…|G:…]` 마커 중 아래 확정 규칙으로 갈리는 것을 미리 해소(워크시트에 `「값」`으로 표시). 판단 불필요, 훑어 확인만.
2. **눈 판단** — 규칙 밖 마커만 `⟦❓n:C/G⟧`로 남겨 워크시트 말미 체크리스트에 모음. Soo가 이미지 대조로 확정. **대분기 마커(§8)는 별도 고난도 트랙**.
3. **정본화** — 확정값 + 자동채움 반영 → `*.high_fidelity.md`, `status: human_verified`. 잔여 `⚠️`·`@`·`draft_v0` 없어야 정본.

워크시트 생성물: `_worksheets/<n>_worksheet.md`, 구조 매니페스트: `_worksheets/_structure/<n>_structure.md`.

## 1. 마커 표기

- `⚠️[C:x|G:y]` — 3엔진(Claude·Gemini·Paddle) 합의 스크립트가 넣은 분쟁 표식. C=Claude, G=Gemini 판독. `∅`=해당 엔진이 비움.
- `` `X@` `` — **Soo의 임시 아래아 표식.** X는 현대형 1음절이고, 이 자리에 아래아(옛한글)가 들어간다는 뜻. 검수 중 빠르게 찍어두고 완료 후 일괄 변환(§4).
- `<n>` — **원문 페이지 경계.** `<1>` 이전이 1면, 이후가 2면. 서지 인용에 쓰이므로 **어떤 자동 처리에서도 보존**한다.

## 2. 표기 정책 (확정)

- **아래아·옛한글 보존.** 현대형/옛한글이 갈리면 옛한글(아래아 `ᆞ` U+119E) 쪽을 택한다. 조합형(초성 U+11xx + `ᆞ` + 종성 U+11xx).
- **어절 띄어쓰기.** 가독성을 위해 어절 단위 공백을 넣는다(원문 세로쓰기엔 없음). 공백만의 분쟁(`C: |G:∅` 류)은 자동 판단 대상이 아니라 어절 판단이 개입하므로, 자동화 단계에선 '붙임 기저'로 잡음만 걷어내고 띄어쓰기는 별도 가독성 층에서 처리.
- **이체자 → 정자 통일**(§3). 단, *같은 글자의 글꼴 변이*만. 서로 다른 글자의 OCR 혼동은 정규화 금지 → 눈.

## 4. 임시 아래아 표식 일괄 변환

Soo가 검수 중 `` `X@` ``로 표시한 아래아 자리를 완료 후 일괄 치환. 도구: `apply_araea.py`.

    python apply_araea.py <파일> --write

변환표(계속 추가):

| 표식 | → 옛한글 |
|---|---|
| `` `는@` `` | ᄂᆞᆫ (U+1102 U+119E U+11AB) |
| `` `한@` `` | ᄒᆞᆫ (U+1112 U+119E U+11AB) |
| `` `나@` `` | ᄂᆞ (U+1102 U+119E) |

원리: 중성 ㅏ/ㅡ를 아래아 ㆍ로 치환. 표에 없는 음절(`것@` 등)은 **미변환·경고**하고 `TABLE`에 한 줄 추가한다. 스크립트는 `<n>`과 그 외 본문을 건드리지 않으며 길이 델타 정합으로 자기검증.

## 5. 기준 파일 원칙

- 정본화의 기준은 항상 **Soo가 손댄 최신 작업본**(워크벤치 사본). 자동화가 옛 원본(`articles/*/transcripts/`)을 기준 삼아 진척을 덮지 않도록 주의.
- 워크벤치 파일에 `` `X@` `` 또는 어절 띄어쓰기가 있으면 = 수작업 진행 중 → 반드시 이어받는다.

## 7. 구조 선분리 (매니페스트)

면주(欄外 running head)·면번호·사진캡션·기사경계 bleed가 OCR 흐름에 침입해 허위 분기 마커를 만든다. `_worksheets/_structure/<n>_structure.md`가 이를 탐지한다. 도구: `manifest_all.py`.

- **면주**: `section` 필드값 + *마커 안에 등장* → 🟢고신뢰(분리). 순빈출 n-gram만이면 🟡(본문 핵심어 가능 → Soo 확인, 자동처리 금지).
- **면번호**: 마커 한쪽이 *통째로 숫자*(二~十, 840류)인 것만. `<n>`은 보존.
- **캡션**: `○…氏`·`敬道師` 패턴. 삭제 아니라 메타로 보존.
- **경계 bleed**: 머리/꼬리 60자에 필자명·인접기사 제목 침입 여부.
- 삭제가 아니라 **탐지→확인→분리**. 탐지는 휴리스틱이므로 🟡·경계는 반드시 Soo 확인.

**코퍼스 분포(47편, 2026-07-01)**: 구조 침입 총 239마커(2%)로 *작다* — C37(캡션3)은 예외편. **인물 캡션 확인편은 매니페스트상 37·73이었으나, 편73 실사 결과 캡션 없이 삽화 1점뿐(매니페스트 오탐)** → 실제 인물 캡션 보유는 37이 확실, 그 외는 편별 실사로 확인. 인물 초상 사진은 49(李仁九·金昌錫)·70(洪鍾燁?)·64 등 산재. 즉 경계·침입 걱정은 소수편에 국한하되 사진·삽화 위치는 편별 확인.

### 8-1. 엔진 실패편 패턴 (편60에서 발견, 2026-07-01)

대분기 과다편의 상당수는 마커별 분쟁이 아니라 **한 엔진이 편 전체에서 붕괴**한 경우다. 판별·처리:

- **판별**: 마커의 한쪽이 계속 반복잡음(`의의의의`, 파편)이고 반대쪽이 계속 장문 완결 → 편 전체 엔진 실패. 첫 이미지 1~2면으로 즉시 확인 가능.
- **처리**: 마커 77개를 개별 중재하지 말 것. **정본 base를 신뢰 엔진으로 flip**, 실패 엔진 폐기. 나머지는 이미지 spot-verify로 ◎.
- **편60 = C(Claude) 붕괴 / G(Gemini) 신뢰.** 다른 편은 반대일 수 있음(엔진 무관).

### 8-2. ⚠️ 페이지 이음매 환각 (필수 점검)

신뢰 엔진이라도 **페이지 넘김 지점에서 문단급 환각을 삽입**할 수 있다. 편60 마커31에서 G가 `(未完)`으로 끝나는 완결형 문단(朝鮮民族·天道敎主義·人乃天思想)을 통째로 지어냄 — 8면 어디에도 없는 텍스트.

- **점검법**: 장문 G-only(또는 신뢰엔진-only) 블록은 반드시 해당 지면 이미지와 대조. 특히 **본문 한복판의 `(未完)`·완결형 종결부**는 환각 신호.
- **위치 단서**: 앞뒤 확정 본문이 면주뿐인 마커 = 페이지 이음매 → 환각 삽입 고위험.
- CLAUDE.md §8(유창한 환각의 wiki 세탁)의 실증. 정본 진입 전 삭제.

### 8-3. 세그먼트 엇갈림편 (desync, 대분기 최다 유형 — 편64서 발견, 1차 파상서 지배적 확인)

대분기 과다편의 **가장 흔한 성격**. **두 엔진 모두 정상**인데 정합(align) 스크립트가 세로단 순서를 놓쳐 같은 지면을 C·G가 각각 장문으로 뱉은 **중복·순서 교란**. 1차 파상(40·46·49·64·67·68·69·79·84·61 등) 검증 결과 대분기 편의 다수가 이 유형이다.

- **판별**: 앞면은 낱글자뿐인데 특정 면에서 대분기가 몰림. `C:[한 면 전체]|G:∅` 또는 한쪽이 solo 평문 블록(반대쪽은 진앙 면의 거대 마커로 흡수)인 마커가 신호.
- **처리**: 어느 엔진도 통째 base 불가. **해당 면 이미지 재구성 척추를 정본 기준**으로 삼고 C·G 블록을 재배열·대조. 척추 확정이 곧 대분기 일괄 해소. (자모 층위에선 옛한글·正字 보존하는 엔진 우세 — 대개 G. 편40·60은 반대이니 편별 확인.)
- **환각과 구별(중요)**: §8-2와 달리 **순서 교란일 뿐 내용 위조 아님** → 장문 블록도 이미지에 전부 있다(전수 대조 필수). 1차 파상 이 유형 전편 환각 0건.
- **유발원은 다양(삽화만이 아님)**: ①인물 초상·분재 삽화(64) ②중앙 제목 배너·장식 괘선(79) ③甲乙丙·三大要點 반복 개요구조(46) ④고밀도 다단/한문 인용 사슬(49·67·84) ⑤display 인용구·붉은 藏書印/독자 밑줄(68·69·61) ⑥페이지 이음매 C 반복루프(degenerate loop) 미러 중복(42). **주의: 삽화 존재 ≠ desync**(편67 p7은 삽화 있어도 desync 무).
- 사진·삽화·캡션은 §7 구조 침입으로 분리(C37 「新任敬道師」 캡션과 동종). 붉은 印章·밑줄은 비텍스트 잉크 침입 → 메타 보존.

### 8-4. 엔진 실패편 flip의 잔여 처리 (편40에서 보강, 2026-07-01)

§8-1 flip(신뢰엔진 base 채택) 후에도 남는 두 잔여를 △로 반드시 처리:

- **未중재 평문 구간**: 정합 스크립트가 실패엔진 base를 **마커 없이** 그대로 남긴 문단(반대엔진 대안 부재) → flip으로 자동복구 불가. **이미지 재구성이 유일 경로**(편40 p2·p3 하단).
- **신뢰엔진 오염 잔재**: 편40 p5에서 Gemini가 일본어 가나(を·に·は·の)를 주입 — 내용은 실재, 가나만 제거. 위조 아니므로 §8-2 환각과 구별.

### 8-5. 기사경계 bleed (필수 분리 — 1차 파상서 빈발 확인)

auto v0 draft는 머리/꼬리에 **인접 기사가 통째로 흘러드는** 경우가 잦다. §7의 경계 bleed를 대분기 트랙에서 특히 강하게 점검:

- 실측 사례: 편40 머리=앞 기사 「侍 訓釋」 좌담 꼬리(화자 張基濂·鄭道永 등), 편84 꼬리=다음 기사 姜仁 「우리의最後目的은…」, 편79 꼬리=다음 기사 「東經大全講解(其二)」, 편42 꼬리=인접 기사 서두. **기념호(44·62)는 축사·명단·화보 혼입 고위험.**

### 8-6. `<n>` 페이지 경계 부재 (auto v0 공통)

거의 모든 auto v0 draft에 `<n>` 페이지 경계 마커가 **없다**(면주 침입으로만 넘김 표시). 정본화 시 면주·면번호 위치를 기준으로 `<1>`…`<면수-1>`을 삽입해야 한다(§1 보존 규칙 대상). 보조판독 워크시트는 이를 △로 명시.
