# 1922년 이전 월보의 唯物·唯心·實在 — 선별 기록

『개벽』 1922년 2월호 「吾人의 新死生觀」이 **唯物/唯心/實在 3분법을 동시대인을 가르는 세 派의
구도로 옮긴 첫 자리인가**를 묻기 위해, 그보다 앞선 시기의 월보를 훑은 기록이다.

**「없다」는 판정은 훑은 범위와 방법이 남아 있어야 검증된다.** 이 문서와
[`../../../scripts/06_magazines/screen_wolbo_keywords.py`](../../../scripts/06_magazines/screen_wolbo_keywords.py)가
그것이다.

```bash
python scripts/06_magazines/screen_wolbo_keywords.py
```

## 1. 범위

| | |
|---|---|
| 수집 월보 이돈화 글 | **86편** (1911-01 ~ 1922-05) |
| 발행일 < 1922-02 | **82편** |
| 그 가운데 전사본이 있는 것 | **81편** |
| 전사본이 없는 한 편 | **C10 통권 18(1912-01)** — 본문이 코퍼스에 없다. **원본 스캔 4장을 직접 판독해 확인했고**, 唯物·唯心·實在·三派가 없다. 이미지는 `data/1_raw_data/wolbo_18/` |

1922-02 이후로 제외한 넷은 C72(1922-02-15)·C73·C74·C75다. 「新死生觀」이 실린 『개벽』
제20호는 1922년 2월 8일 발행이므로 이 넷은 모두 그 뒤다.

⚠️ **훑은 81편은 전부 미검수 초벌이다**([`../../docs/02b_digitization_magazines.md`](../../../docs/02b_digitization_magazines.md) §2).
곧 이 선별은 **후보를 좁히는 도구**이며, 판정은 원본 지면과 대조해서 세운다.

## 2. 🔴 마커가 낱말을 쪼갠다 — 단순 검색은 과소 계수한다

초벌 전사는 엔진이 갈린 자리를 `⚠️[C:…|G:…]`로 보존한다. **이 마커가 낱말 한가운데를 지날 수
있다.**

```
…美善眞이라實⚠️[C:在라ᄒᆞ|G:存이라호]며理性이라…
```

원문은 「實在」다. 그런데 Claude가 實**在**로, Gemini가 實**存**으로 읽어 마커가 「實」과 「在」
사이를 갈랐다. **문자열 `實在`를 그냥 찾으면 걸리지 않는다.**

실제로 이 한 자리 때문에 C56이 후보에서 빠질 뻔했다. 그 편은 **본 연구가 인용하는 두 대목
가운데 하나**다.

### 방법

마커를 **C쪽·G쪽으로 각각 펴서 두 판을 만들고 양쪽에서 센다.** 어느 한 판에라도 걸리면
후보다. `∅`(그 엔진은 아무것도 읽지 않았음)는 빈 문자열로 편다.

| | 단순 검색 | 두 판 검색 |
|---|---|---|
| 후보 편수 | 9편 | **10편** |
| C56 | ❌ 놓침 | ✅ |

**한 판에서만 세도 안 된다.** 다른 엔진이 읽은 것을 놓친다.

⚠️ **두 판을 다 펴도 두 엔진이 같이 놓친 것은 잡지 못한다.** 이것이 이 선별에 남는 한계다.

## 4. 열 편을 읽고 고른 둘

열 편을 읽어 **논법의 구조가 걸리는 것** 둘을 골라 원본 지면과 대조했다. 나머지 여덟 편의
實在·唯心은 3분법의 구도와 무관한 낱말 단독 쓰임이다.

| 편 | 무엇이 있나 | 3분법인가 |
|---|---|---|
| **C81** (1918-10) | 唯心論→唯物論→物心合一論. **삼항의 틀** | ❌ 앗시리아→희랍→로마와 나란한 **학설의 시간적 계승**. 동시대인의 분파가 아니다 |
| **C56** (1920-01) | 科學者/哲學者 분류 + 哲學者에 대한 實在 귀속 + 「敵論이 紛紛」 | ❌ 하나를 여럿이 달리 부른다는 **열거**. 셋으로 가른 구도가 아니다 |

대조의 상세는 [`verified_passages.md`](verified_passages.md)에 있다.

**결론.** 재료(삼항의 틀·분류 어휘·갈려 다툰다는 문제의식)는 1918~1920년에 이미 있었다.
1922년에 새로 생긴 것은 재료가 아니라 **배치**다.
